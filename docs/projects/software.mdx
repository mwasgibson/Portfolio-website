## EpiPredict Kenya AI

[EpiPredict Kenya AI](https://github.com/mwasgibson/epi-predict-kenya-ai) is a disease-outbreak prediction project organized into frontend, API, and machine-learning services. The repository includes database persistence and container-based workflows.

## Site Trust Checker

[Site Trust Checker](https://github.com/mwasgibson/site-trust-checker) combines website security signals through a browser extension and API. An important design consideration is representing uncertainty rather than presenting a trust score as absolute certainty.

## CineStudio

[CineStudio](https://github.com/mwasgibson/cinestudio) is an AI-assisted script workstation for screenplay, A/V, and stageplay formats. Its planned and developing workflows include storyboard timing, a multi-track timeline, and post-production exports.

## LogHub

[LogHub](https://github.com/mwasgibson/loghub) is a multi-project log and metrics viewer. The broader product direction includes web, mobile, and CLI clients.

## Quilroom

[Quilroom](https://github.com/mwasgibson/quilroom) is a self-hosted real-time collaborative document editor designed for local networks. Its feature set includes presence, autosave, and QR-assisted sharing.

## Lab

[Lab](https://github.com/mwasgibson/lab) explores browser-based augmented reality and spatial previews using 3D presentation tools.

## FileConv / Grubber

[Grubber](https://github.com/mwasgibson/grubber) is a Python CLI file-conversion tool built with Typer. It uses a converter registry, MIME-type resolution, and specialist conversion backends.

Repository READMEs provide the latest installation instructions, implementation status, and usage details.
