## EpiPredict Kenya AI

I am developing [EpiPredict Kenya AI](https://github.com/mwasgibson/epi-predict-kenya-ai) as a disease-outbreak prediction project organised into frontend, API, and machine-learning services. The repository includes database persistence and container-based workflows.

## Site Trust Checker

I built [Site Trust Checker](https://github.com/mwasgibson/site-trust-checker) as a browser extension and API that combine website security signals. I pay particular attention to representing uncertainty rather than presenting a trust score as absolute certainty.

## CineStudio

I am developing [CineStudio](https://github.com/mwasgibson/cinestudio), an AI-assisted script workstation for screenplay, A/V, and stageplay formats. Its workflows include storyboard timing, a multi-track timeline, and post-production exports.

## LogHub

I am working on [LogHub](https://github.com/mwasgibson/loghub), a multi-project log and metrics viewer. Its broader direction includes web, mobile, and CLI clients.

## Quilroom

I am building [Quilroom](https://github.com/mwasgibson/quilroom), a self-hosted real-time collaborative document editor designed for local networks. Its feature set includes presence, autosave, and QR-assisted sharing.

## Lab

I use [Lab](https://github.com/mwasgibson/lab) to explore browser-based augmented reality and spatial previews using 3D presentation tools.

## FileConv / Grubber

I built [Grubber](https://github.com/mwasgibson/grubber), a Python CLI file-conversion tool using Typer, a converter registry, MIME-type resolution, and specialist conversion backends.

For current installation instructions and implementation status, I keep the repository READMEs as the source of truth.
