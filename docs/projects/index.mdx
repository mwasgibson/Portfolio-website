## Developer tools and applications

- **[Site Trust Checker](https://github.com/mwasgibson/site-trust-checker):** browser extension and API for combining website security signals and expressing uncertainty in trust scoring.
- **[CineStudio](https://github.com/mwasgibson/cinestudio):** an AI-assisted script workstation supporting screenplay, A/V, and stageplay formats, with storyboard timing, a multi-track timeline, and post-production exports.
- **[LogHub](https://github.com/mwasgibson/loghub):** a multi-project log and metrics viewer, with web, mobile, and CLI clients in its planned scope.
- **[Quilroom](https://github.com/mwasgibson/quilroom):** a self-hosted real-time collaborative document editor for local networks, with presence, autosave, and QR-assisted sharing.
- **[Lab](https://github.com/mwasgibson/lab):** an exploratory browser-based AR and spatial-preview concept using 3D presentation tools.
- **[FileConv / Grubber](https://github.com/mwasgibson/grubber):** a Python command-line file conversion tool using a converter registry, MIME-type resolution, and specialist backends.
