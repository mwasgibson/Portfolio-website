I contribute to the [SCAAI Desktop community](https://github.com/Nooran3994/SCAAI-COMMUNITY) through release testing and feedback.

My involvement has included:

- Testing released application builds.
- Observing and reporting onboarding and persistence behaviour.
- Documenting reproducible user-facing issues.
- Providing feedback on community documentation and project coordination.

One observed issue involved the application returning to onboarding after a restart. Subsequent testing after a full computer restart did not reproduce the behaviour, so it was reported as an intermittent observation rather than a confirmed persistent defect.

The public community repository contains release and coordination materials; it does not publish the desktop application's source code. My contribution should therefore be understood as community testing and feedback, not authorship of the desktop application.
