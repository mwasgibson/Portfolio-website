## Selected work

- **[Shea](https://github.com/mwasgibson/Shea):** a modular, user-sovereign AI agent runtime focused on planning, policy, authorization, controlled execution, verification, recovery, and auditability.
- **[EpiPredict Kenya AI](https://github.com/mwasgibson/epi-predict-kenya-ai):** a disease-outbreak prediction project structured around frontend, API, and machine-learning services.
- **[Site Trust Checker](https://github.com/mwasgibson/site-trust-checker):** a browser extension and API that combine website security signals while accounting for uncertainty.
- **[CineStudio](https://github.com/mwasgibson/cinestudio):** an AI-assisted script workstation for screenplay, A/V, and stageplay workflows.
- **[Quilroom](https://github.com/mwasgibson/quilroom):** a self-hosted collaborative document editor for local networks.

Project status varies. Some are active development efforts, while others are completed builds, experiments, or exploratory concepts. Individual project descriptions make that distinction explicit.
